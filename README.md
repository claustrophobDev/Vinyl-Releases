# Vinyl для Windows

Официальный канал загрузок и обновлений Vinyl — портативного клиента на sing-box.
Здесь публикуются архивы программы, описания изменений и контрольные суммы.
Исходники приложения ведутся в отдельном репозитории.

Первый публичный выпуск готовится. Проверенная сборка появится в разделе
[Releases](https://github.com/claustrophobDev/Vinyl-Releases/releases).

## Выбор архива

| Windows | Архив |
|---|---|
| x64, Intel / AMD | `Vinyl-<версия>.zip` |
| ARM64 | `Vinyl-<версия>-arm64.zip`, когда он приложен к выпуску |

Архив ARM64 должен содержать родные приложение, ядро и драйвер. Эмуляция x64
на ARM Windows не заменяет ARM64-драйвер туннеля.

## Запуск

Распакуйте весь архив и запустите `vinyl.exe`. Добавьте свою подписку или ключ
на экране «Серверы» и подключитесь с главного экрана. Подписка и сервер в комплект
не входят. Режим туннеля запрашивает права администратора; системный прокси
работает без них и охватывает приложения, использующие настройки прокси Windows.

Настройки хранятся в папке `data` рядом с программой. Перед заменой файлов
закройте Vinyl и сохраните эту папку. Настройки также можно экспортировать из приложения.

## Проверка загрузки

Сравните SHA256 архива с `SHA256SUMS.txt` в том же выпуске:

```powershell
Get-FileHash -Algorithm SHA256 .\Vinyl-<версия>.zip
```

Статус подписи и проверенные версии Windows указываются в описании выпуска.
Самоподписанный сертификат не даёт доверия на другом компьютере; SmartScreen
может показывать предупреждение. Не отключайте защиту Windows ради установки.

## Обновления

Приложение проверяет стабильные выпуски этого репозитория без токена GitHub.
Если есть новая версия с архивом для вашей архитектуры Windows, оно предлагает
открыть страницу выпуска. Замена файлов происходит вручную.
